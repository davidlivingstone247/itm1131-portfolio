Self-Check

1. What was the most challenging part of this exercise, and how did you work through it?

The most challenging part was adding images using the correct file paths. I worked through it by creating an images folder, placing the pictures inside it, and checking that the image filenames matched the names written in the HTML code.

2. How does what you just practiced connect to today's focus, "Lists, Tables, Links & Images"?

The exercise helped me practise all four areas. I used a list for my learning goals, a table for my favourite course modules, links for navigation and the Muni University website, and images to add visual information to my profile page.

3. If you got stuck at any point, what would you try differently next time?

Next time I would check my HTML tags, filenames and folder paths carefully. I would also test the page in a browser and correct one error at a time instead of changing many things at once.
